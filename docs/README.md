# ILM Documentation

These guides describe the repository as a reusable SDK and a reproducible
research project. Historical notes and discarded design paths remain in the
ignored `reflect/` directory.

- [Tokenization](tokenization.md): tokenizer methods, released artifacts,
  semantic-label sidecars, and embedding caches.
- [Training](training.md): sandbox checkpoints, architecture flags, and model
  metadata.
- [Evaluation](evaluation.md): generation comparisons and external references.
- [Reproducibility](reproducibility.md): the controlled experiment layout and
  evidence plan, deterministic splits, and result aggregation.
- [Paper Workspace](paper.md): long-form and NeurIPS manuscript builds.

[HOWTO.md](../HOWTO.md) remains the command-oriented guide for the interactive
scripts.
