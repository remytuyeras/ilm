# Experiments

This directory contains reproducible study definitions rather than exploratory
checkpoints. Corpus sources remain in `data/corpora/`, reusable released
tokenizers remain in `data/tokenizers/`, and selected manuscript artifacts live
in `paper/artifacts/`.

The first registered study is the [controlled evaluation](evaluation/README.md).

- [METHOD.md](METHOD.md) is the executable record for the current controlled
  study.
- [DISCUSSION.md](DISCUSSION.md) records hypotheses, interpretation, and
  evidence still needed before making research claims.
